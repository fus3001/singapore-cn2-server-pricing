## 常见问题

**绿云新加坡的 IP 会不会被墙？**
这取决于你买哪条线和当时的网络环境，没有商家能承诺 IP 永远可用。优化线路本身就是为了降低被干扰的概率，但任何新加坡 VPS 都存在换 IP 的可能，这是海外服务器的固有风险。

**CN Premium 系列带 Windows 吗？**
官网页面上该系列标注 Linux OS，没有 Windows 选项。需要 Windows 的话要看它家单独的 Windows VPS 产品线，或者选支持 Windows 镜像的国内商家。

**每日备份是免费的吗？**
CN Premium 系列的套餐页面把 Daily Backups 列在标配里。普通 KVM 系列是否包含备份，以各套餐页面的实际标注为准，别默认所有套餐都带。

**月付和年付差多少？**
优化线路目前主要按月付销售（Mini 档 25 美元/月），普通系列年付单价明显更低，比如历史上新加坡 NVMe 套餐年付 20 美元起。年付虽便宜，但结合前面说的退款政策，长周期套餐一旦不合适就很难退出，第一次买建议先月付观察。
